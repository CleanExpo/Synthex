# Google Authority Packets

Authority packets tell Phill exactly what Google action is needed for each business. They are generated by:

```bash
npm run connections:google:audit
```

The latest generated packet is written to:

```text
docs/marketing-agency/google-authority-packets/latest.md
```

## Packet Rules

- Say which business must be active in Synthex before approval.
- Link only to Synthex OAuth starter URLs or Google-owned authority surfaces.
- Never include secret values.
- Never ask for raw tokens, passwords, cookies, service-account JSON, or OAuth client secrets in chat.
- Keep read-only checks separate from mutation approvals.

## Authority Actions

Common actions:

- Approve Search Console OAuth.
- Verify Search Console domain ownership.
- Approve GA4 OAuth.
- Select or grant access to the correct GA4 property.
- Approve Google Business Profile OAuth.
- Accept or request GBP owner/manager access.
- Approve YouTube channel OAuth.
- Approve Google Drive OAuth.

If Google requires a restricted-scope verification or paid security assessment, route it to the Board before proceeding.
