# Synthex campaign file — CARSI Australian H5 readiness

## Agency role

Synthex is the marketing agency of record for the CARSI Australian H5 readiness campaign.

## Campaign hub

https://carsi.com.au/avian-influenza-readiness

## Objective

Build maximum search, answer-engine and generative-engine eligibility for the CARSI H5 readiness campaign while preserving official Australian Government wording and avoiding public alarm.

This does not guarantee a #1 ranking. It documents the ranking foundation: content quality, source traceability, schema, crawl/indexing workflows, Core Web Vitals discipline and backlink coordination.

1. E-E-A-T and source authority.
2. Technical SEO and sitemap inclusion.
3. JSON-LD schema validation.
4. AEO quick-answer blocks.
5. GEO citation-ready source and entity graph.
6. Google Search Console and Bing Webmaster Tools submission workflow.
7. IndexNow submission.
8. Cross-brand backlinks from Synthex, RestoreAssist, DisasterRecovery.com.au and NRPG.
9. LinkedIn and media packaging.
