# Google Business Connection Register

Generated source of truth for the seven businesses under `phill.mcgurk@gmail.com`.

Run:

```bash
npm run connections:google:audit
```

The command writes the latest actionable authority packet to:

```text
docs/marketing-agency/google-authority-packets/latest.md
```

## Register Columns

- Business
- Website
- Required Google Search Console state
- Required GA4 state
- Required Google Business Profile state
- Recommended YouTube state
- Recommended Google Drive state
- Founder authority action
- Evidence collected
- Synthex sync result
- QA result
- Final status
