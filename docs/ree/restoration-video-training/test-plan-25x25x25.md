# 25 x 25 x 25 training plan

What the three 25s mean:

- **25 scenarios**: real restoration situations an Australian property owner meets (table S).
- **25 checks**: every script, storyboard and later every rendered video is scored against all of them (table K).
- **25 rounds**: each round runs all 25 scenarios through all 25 checks. Every failure becomes a rule change before the next round, so the system gets stronger round by round.

One full cycle is 25 x 25 = 625 scored judgements per round, 15,625 across the plan.

## Round protocol

Round 1 (baseline): write a script and shot list for each of the 25 scenarios using the reel
lessons. Score all 625 judgements. Expect failures; record every one.

Each later round (2 to 25):

1. Fix the rule, not the script: each failure from the last round becomes a change to a skill, a brief template or this register, with the failure it fixes named.
2. Regenerate all 25 scripts from the updated rules (not hand-patched).
3. Score blind: the judge sees the script and the checks, not the builder's reasoning. Use a different model or vendor from the builder where an account lane is available.
4. A check that has passed for 3 rounds in a row is made harder (for example K4 moves from "Australian house" to "named Australian housing type matches the scenario's era").
5. Record the round in a scoreboard: passes per check, passes per scenario, rule changes made.

Round gates:

- Rounds 1 to 5: scripts and storyboards only.
- From the round after owned job footage lands: animatic or edit from our own footage, scored on all 25 checks including measured K17, K20 and K22 with `analyze.py --single`.
- No video is published from this plan without Phill's approval and the video boards.
