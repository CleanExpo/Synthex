# IntentScape Context

IntentScape turns an incomplete human signal plus independent evidence into competing, audited directions. It keeps provenance, hypotheses, approved goals, and executable work as separate concepts so the first sentence cannot silently become the mission.

## Language

**Origin Signal**:
The human's initial expression of a situation, preserved as provenance without goal or action authority.
_Avoid_: Prompt, mission, task, final query

**Context Field**:
A versioned collection of signals, contradictions, unknowns, constraints, and evidence describing the situation around an Origin Signal.
_Avoid_: Chat history, prompt context

**Vision Lens**:
One of the fixed, independent perspectives used to expand a Context Field beyond the language and solution implied by the Origin Signal.
_Avoid_: Skill, selected agent, source router

**Research Branch**:
A bounded investigation created to resolve a decision-relevant gap exposed by a Vision Lens.
_Avoid_: Restated prompt, generic web search

**Hypothesis**:
A versioned causal direction that can compete with other explanations and has no goal or action authority.
_Avoid_: Recommendation, mission, approved plan

**Goal Contract**:
The immutable human promotion of one exact, audited Hypothesis version with acceptance criteria, exclusions, and authority boundaries.
_Avoid_: Prompt, editable mission, model decision

**Work Packet**:
A bounded execution handoff derived only from an approved Goal Contract.
_Avoid_: Raw request, Command Packet from input

**Wiki Artifact**:
An immutable, hash-verified Markdown version containing canonical IntentScape knowledge.
_Avoid_: Database payload, transient model output
