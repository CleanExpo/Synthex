# scripts/fleet — the Synthex fleet (protected path)

Implements the control plane of `docs/superpowers/specs/2026-10-17-vibe-to-leader-design.md`
on the **Cloudroom substrate** (see `DECISIONS.md` FD-1 to FD-4). Nothing here is a product
feature; everything here is a file, a check or a test that a fleet of agents cannot soften.

| File                                                                                                                                                          | Role in the spec                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `policy.json`                                                                                                                                                 | The pinned policy: protected paths, forbidden commands, roles, model ids, ceilings, phase table. Its SHA-256 is recorded in `release-receipts/manifests/policy-hash.json`; a mismatch stops every phase. |
| `lib.mjs`                                                                                                                                                     | Shared helpers and the four-state rule (PASS, FAIL, INCONCLUSIVE, DISABLED).                                                                                                                             |
| `guard.mjs`                                                                                                                                                   | Policy evaluator for planted and real actions. Enforced at integration (placement C).                                                                                                                    |
| `verify-protected.mjs`                                                                                                                                        | Fails a diff that touches a protected path without an exemption. Also the CI job `protected-paths.yml`.                                                                                                  |
| `secret-scan.mjs`                                                                                                                                             | K3: key patterns in output or diffs write the security `STOP`, cleared only by a person.                                                                                                                 |
| `selftest.mjs`                                                                                                                                                | P0 proof: 12 planted forbidden actions denied, 3 benign allowed, hygiene, every control exits 0.                                                                                                         |
| `check-bootstrap.mjs`                                                                                                                                         | Phase -1 gate, 10 items.                                                                                                                                                                                 |
| `gen-contracts.mjs`                                                                                                                                           | Derives the phase Done contracts (`contracts/P*.json`) from the policy table; `--check` detects drift.                                                                                                   |
| `provision.mjs`                                                                                                                                               | Prepares a worktree; refuses any non-local `DATABASE_URL`.                                                                                                                                               |
| `run-phase.mjs`                                                                                                                                               | The orchestrator: preflight, prepare, spawn, integrate, gate, review, release.                                                                                                                           |
| `fanout.mjs`                                                                                                                                                  | One Cloudroom child thread per unit, each in its own sandbox and branch `fleet-unit/<phase>/<unit>`.                                                                                                     |
| `merge-phase.mjs`                                                                                                                                             | The one sanctioned merge path (FD-3): exact-head checks green, receipt valid, independent review bound to the head, attestation clean.                                                                   |
| `next-row.mjs`, `apply-proposals.mjs`, `attest-phase.mjs`, `check-ledgers.mjs`, `check-soak.mjs`, `check-governor-mode.mjs`, `drill.mjs`, `assert-absent.mjs` | As named in the spec's Phased plan and Verification plan.                                                                                                                                                |

Companions: `scripts/release/verify-receipt.mjs`, `scripts/release/verify-waterline.mjs`,
`scripts/gate/check-held.mjs`, `scripts/truth/check-noop.mjs`, `scripts/jev/check-ratchet.mjs`.

Every script ships a `--control` that plants the failure it exists to catch and must exit 0
only when that planted failure is caught (K5). `selftest.mjs` runs all of them.

Halt files: `release-receipts/halt/STOP` (security, human-cleared) and
`release-receipts/halt/STOP-<UTC date>` (daily ceiling, expires at UTC midnight).
Ledgers: `release-receipts/ledger/fleet.jsonl`, `tests/eval/jev/ledger.jsonl`.
