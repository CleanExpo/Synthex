# Demo Flows

Loom scripts, walkthrough notes, and screenshots for demonstrating Synthex features.

## Current demo assets

Add files here when preparing a demo for a client or for internal review.

### File naming convention

```
demo/ccw-image-gen-walkthrough.md
demo/media-library-loom-script.md
demo/carsi-campaign-flow.png
```

## Key flows to demo

1. **AI Image Generation** — Upload reference photos → generate campaign images → tap to rank → retrain
2. **Media Library** — Browse, upload, organise brand assets
3. **Campaign automation** — Draft → approve → schedule → post to platforms
4. **GBP management** — Location sync, posting, review responses
